# SommelIAr – Mis notas de vino

Plataforma web para gestionar vinos y consultar un “sommelier IA”.

## Estructura
- `backend/`: API Node.js con Express.
- `frontend/`: Cliente React creado con Vite.

## Puesta en marcha
1. Backend
   ```bash
   cd backend
   npm install
   npm run dev
   ```
2. Frontend
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
